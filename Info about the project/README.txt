# Take Care of Green Square
You can drag food to the moving green square and feed it... 
The green square is pleased with you nourishing them.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Have a computer that will even run Godot
2. Get Godot version 4 (This is IMPORTANT that you specifically download this version since some of the code is not compatible with older versions)

Instructions for using the software:

1. Download the things needed which is right above here
2. Import the project from Github to Godot (Again make sure you have version 4 otherwise it aint gonna work)
3. Open this project from the file 
4. Press the little sideways triagle when hovered on it says Run Project
5. Enjoy the game!
